# Musée

Scénario repris du Notion (« Les cartes lieux », mars 2023). Pas encore dans le jeu ; seul le tableau est écrit.

## Pourquoi on s'arrête

La boussole horaire du vaisseau doit être redémarrée, et l'autopilote vous a dirigés vers le point d'intérêt le plus proche : un musée, où vous pourrez attendre que les systèmes se recalibrent.

## Les trois voies

| | Choix 1 | Choix 2 | Choix 3 |
| --- | --- | --- | --- |
| Étape | PNJ quête | PNJ interaction | Combat contre un groupe de mobs |
| Ce qui se passe | Coincer un voleur qui frappe le musée tous les soirs (boss ou mob élite selon la récompense) | Voler la boule de Chris Tale exposée | Récupérer ce que les mobs avaient sur eux |
| Récompense | Une arme légendaire (on est dans un musée) | Une boule de Chris Tale | Composants ou consommables |
