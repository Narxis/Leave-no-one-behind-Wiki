# Observatoire

Scénario repris du Notion (« Les cartes lieux », avril 2023). Pas encore dans le jeu.

## Pourquoi on s'arrête

Des turbulences ont perturbé les systèmes de navigation et obligé l'autopilote à recalculer l'itinéraire. Vous pouvez récupérer des données de navigation à l'observatoire le plus proche. Les scientifiques vous accueillent : c'est un observatoire [de_race_1].

## Les trois voies

| | Choix 1 | Choix 2 | Choix 3 |
| --- | --- | --- | --- |

| Ce qui se passe | Protéger les serveurs de l'observatoire | Répondre aux questions du scientifique | Résoudre une énigme |
| Récompense | Données de navigation, outil de réparation | Données de navigation, boule de Chris Tale | Données de navigation, +intelligence |

## Choix 1 : suivre le scientifique dans le couloir

Au milieu du trajet, une alarme retentit. Le scientifique reçoit un appel, puis se tourne vers vous :

« Désolé de vous demander ça précipitamment, mais l'observatoire est attaqué par une bande de Shrymps. Cela fait plusieurs jours qu'ils essaient de pirater notre base de données. Nous ne savons rien d'eux, à part qu'ils se nomment les Shrymps Hackers d'Informations Antifongiques Sécurisés. Ils ont abandonné le piratage et passent à la manière forte. Ils sont dans le hall d'entrée par où vous êtes passés. Pouvez-vous nous aider ? Nous n'avons aucun moyen de nous défendre. »

- **Aider l'observatoire.** Vous faites demi-tour et tombez sur les Shrymps. Le combat est presque inévitable.
  - **Finir le combat.** Un scientifique vous remercie avec un outil de réparation et vous rend vos données de navigation. Vous retournez au vaisseau.
    *MJ : gain de réputation auprès [des_race_1].*
  - **Négocier avec les Shrymps** (Ygrl nécessaire dans l'équipage). Les Shrymps sont désemparés d'avoir attaqué une Ygrl ; ils ne savent plus quoi faire.
    - **Les repousser de l'observatoire.** Mêmes récompenses que le combat. *MJ : gain de réputation auprès [des_race_1].*
    - **Les aider à attaquer l'observatoire.** Vous traversez les lieux sans peine jusqu'à la salle des serveurs. Les Shrymps récupèrent efficacement vos données de navigation, et vous quittez vite le bâtiment.
      *MJ : perte de réputation auprès [des_race_1].*
- **Retourner au vaisseau.** Vous fuyez l'observatoire sans vos données de navigation.
